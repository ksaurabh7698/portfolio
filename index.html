3D Data Structures & Algorithms Visualizer

Three.js Blender Unreal Engine InstancedMesh

Designed to help computer science students intuitively grasp spatial structures—such as balanced trees (Red-Black, B-Trees) and graph traversals—in real time directly in the browser without heavy downloads. Features a custom step-by-step execution queue decoupling algorithm logic from frame rendering, allowing users to pause, rewind, and inspect pointer reassignments dynamically.

Technical Bottleneck & Resolution

The Problem: When rendering over 1,000 nodes with animated edge re-balancing, frame rates dropped below 15 FPS due to creating individual meshes and materials for every node and edge (generating over 1,000 draw calls per frame).

Investigated & Fixed: Used Chrome DevTools and Three.js WebGLRenderer.info to trace the draw-call overhead. Refactored the layer to use THREE.InstancedMesh for nodes (consolidating hundreds of calls into 1) and merged dynamic edge lines into a single BufferGeometry.

Impact: Locked 60 FPS smoothly handling 2,500+ active tree nodes during recursive rotations.
